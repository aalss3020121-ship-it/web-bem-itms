# web-bem-itms
Portal Berita BEM ITMS adalah platform informasi digital berbasis web modern yang dirancang sebagai pusat publikasi kegiatan, wadah aspirasi mahasiswa, serta transparansi informasi dari seluruh kementerian di bawah Badan Eksekutif Mahasiswa Institut Teknologi Muhammadiyah Sumatera (ITMS) Kabinet Biru Laut
